Instead of only generating text or answering questions, agentic systems use large language models as a "central nervous system" to independently plan, use tools, collaborate with other agents, and run multi-step workflows.

Part 1

The evolution of agentic AI

Four eras, from rigid rules to models that plan and act. Under each one: where our repo's work sits.

  1. 1990s–2010s

    Rule-Based Automation

    Powered by rigid if-then structures, basic scripts and early Robotic Process Automation (RPA). These systems could only handle highly predictable tasks and had no real decision-making capability.

  2. 2010s–2020

    Conversational AI & Early ML

    Driven by intent-recognition machine learning, which gave rise to voice assistants like Siri and basic customer-service chatbots. They were context-aware but limited to answering single questions without real-world utility.

  3. 2020–2023

    Generative AI

    LLMs like GPT-3 and GPT-4 let machines generate new content and code and reason through logic puzzles. But it stayed System 1 thinking: reactive, prompt-dependent, with no long-term memory and no real-world read-write access.

  4. 2023–present

    Agentic AI

    LLMs are packaged inside cognitive loops. They take an open-ended goal, break it into a task list (planning), fetch documents (RAG), write code, call third-party APIs (tool use), review their own errors, and adjust until the goal is reached.

Generative AI

Prompt in, text out. Reactive, no memory, no access to the world.

→

Agentic AI

Goal in, outcome out: plan → act with tools → observe → review → repeat.

Part 2

Current standards & ecosystem

What an agentic system is expected to do in 2026. Next to each standard is what our repo does about it, pulled from the tasks in our build phases.

1

Communication & tool integration protocols

Model Context Protocol (MCP)

Pioneered by Anthropic

An open, plug-and-play architecture that lets LLMs safely read data from local files, connect to databases, and invoke software environments in a uniform way.

Agent Communication Protocol (ACP) & AGP

Promoted by IBM and the Linux Foundation

REST- and gRPC-based enterprise protocols for how multi-agent swarms orchestrate data, signal one another, and transfer tasks across secure architectures.

Function calling protocols

Formalized by OpenAI and the community

Predictable schema formats, like JSON, so agents don't hallucinate arguments when they trigger code execution.

2

Architecture & orchestration

Multi-agent frameworks

LangGraph, AutoGen

Instead of one monolithic agent doing everything, work flows through standard roles: a Planner splits tasks, a Researcher calls APIs, an Executor runs code, and a Reviewer checks output quality.

State management

Short-term and long-term memory

Agents are no longer stateless. Short-term working memory lives in scratchpads; long-term memory lives in vector databases that track preferences and history.

3

Security, identity & governance

Machine-to-machine authentication

OAuth, access tokens

Agents verify their software identity with OAuth and dedicated access tokens before they query databases.

Dynamic permissions & sandboxing

Least privilege

Agents run in isolated code sandboxes with least-privilege permissions, for example a cap on how many tools an agent can invoke before it has to re-authenticate.

Human-in-the-loop (HITL)

Approval checkpoints

High-risk operations, like a bank transaction or a change to a cloud database, stop at a hard checkpoint until a human approves them.
